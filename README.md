# BMU Timetable & Room Navigator

Интерактивная система занятости аудиторий и расписания British Management University (Ташкент), синхронизированная с порталом EduPage.

## Возможности
- **Сетка аудиторий:** просмотр занятости любого кабинета (2–5 этажи, лекционные, компьютерные, семинарские) на всю неделю.
- **Поиск свободного кабинета:** мгновенное разделение кабинетов на свободные и занятые по выбранному дню и времени (или в реальном времени).
- **Расписание групп:** просмотр расписания для любой студенческой группы (Foundation, Year 2–4).
- **Тёмная тема:** строгий современный тёмный интерфейс без визуального шума.
- **Авто-обновление данных:** GitHub Actions автоматически проверяет и обновляет данные расписания каждое утро перед началом занятий.

## Автоматическое обновление
Файл `.github/workflows/update.yml` настроен на запуск по расписанию (пн–пт в 08:00 по Ташкенту). Также в любой момент можно запустить обновление вручную во вкладке **Actions** -> **Update BMU Timetable** -> **Run workflow**.

## Локальный запуск
Просто откройте `index.html` в любом браузере.
Для ручного обновления данных локально:
```bash
python update_timetable.py
```
